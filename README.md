## Tecnologias usadas
- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML

## Como executar

1. `pip install -r requirements.txt`
2. `python app.py`

## Comandos Git
- `git init` - inicia o repositório.
- `git add .` - adiciona os arquivos.
- `git commit -m "Primeiro commit"` - salva as alterações.
- `git branch -M main` - define a branch principal.
- `git remote add origin LINK_DO_REPOSITORIO` - conecta ao GitHub.
- `git push -u origin main` - envia os arquivos ao GitHub.
